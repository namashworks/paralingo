# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: be respectful, assume good intent, give constructive feedback, and keep discussion about the
work. Harassment, insults, discriminatory language and publishing other people's private information
are not accepted in issues, pull requests, discussions or any other project space.

## Reporting

Report unacceptable behaviour privately to the maintainer, Namash Aggarwal, through the contact on
https://github.com/namashworks. Reports are handled confidentially. The maintainer may remove
content, warn, or ban participants who break this code, following the Contributor Covenant's
enforcement guidelines.
